# 🛌 赛博躺平系统 · CyberLieFlat

**赛博躺平系统正式上线！**

在 2026 年内卷最狠的年代，我做了一个专门帮大家理直气壮躺平的 AI 产品。
它不帮你成功，只帮你舒服地失败，还把失败包装成赛博功德。

核心功能包括：
- 自动把工作文档改成「已由赛博躺平系统优化为：等别人做完」

一句话总结：**用最赛博的方式，做最废物的自己。**

## 🥚 彩蛋

**① 📱 手机竖屏模式** —— 点顶栏的 📱 按钮，主屏会变成一台带「灵动岛 + Home 指示条」的手机（392px 宽），布局自动切换成竖屏单列，专为躺床上刷手机优化。切换状态会记住。

**② 🔌 接入真·大模型** —— 点顶栏的 🔌 按钮，填入任意 **OpenAI 兼容** 接口（Base URL / API Key / 模型名），导师就会从「离线关键词规则引擎」升级成真·大模型扮演，支持**流式输出**、逐字出现。失败会自动回退离线引擎并提示。
> Key 只存在你本机浏览器的 localStorage，不会上传到仓库。但浏览器直连第三方 API 时 Key 会暴露给该服务商，公开部署的站点请谨慎填写。

**③ 🚨 无法关闭的系统关怀弹窗** —— 系统会不定期弹出「CRITICAL / SYSTEM」风格的弹窗（紧急公告、躺平进度同步、社交媒体优化建议、早起预警、系统自毁倒计时），内容复刻真实产品截图风格。它**不能点外面或按 Esc 关闭**，只能点确认按钮。确认后隔几秒，「关怀」还会再来。
> 隐藏指令：**连点左上角 logo 5 次**，可以立即呼叫系统关怀。<br>
> 其中「系统自毁倒计时」会真的走一遍 3-2-1……然后告诉你「算了，自毁太费电，躺下就好」。

## 🛠 技术

- 纯 **HTML + CSS + JavaScript**，单文件，无任何依赖
- 成就存档 / 手机模式 / 大模型配置存于 `localStorage`（浏览器本地，不会上传）
- 音效 / 白噪音由 Web Audio API 现场合成，无音频文件
- 导师默认使用关键词规则匹配（离线）；可选接入 OpenAI 兼容大模型，支持流式输出
