# 🛌 赛博躺平系统 · CyberLieFlat

> 用最赛博的方式，做最理直气壮的废物。
> AI 不帮你成功，只帮你舒服地失败，还把失败包装成赛博功德。

一个纯前端、零依赖、单文件的交互 Demo。植入你所有电子设备的「反内卷插件」——它不帮你提高效率，只帮你用最炫酷的方式摸鱼、偷懒、理直气壮地躺下。当你试图努力时，它会用各种赛博手段阻止你。

## 🚀 在线体验

👉 **https://Kimberlying.github.io/cyber-lie-flat/**

也可以直接下载 `index.html`，双击用浏览器打开（无需联网、无需安装）。

## 🎮 功能

| 模块 | 说明 |
| --- | --- |
| 🧘 AI 躺平学导师 | 请出「庄子·赛博版 / 章鱼哥 2077 / 躺平系统本体」三位虚拟先贤，一句话消解你所有的上进心 |
| 📉 自动降级处理 | 输入任何「努力」内容，系统自动优化成最理直气壮的偷懒方案 |
| 🪑 数字纸扎工位 | 纸扎替身替你打工，老板看到的永远是「绿色忙碌」 |
| 🛑 内耗消除弹窗 | 一键承认自己是废物 / 假装天才，播放「电钻声 × 冥想」白噪音 |
| 🏆 反向成就系统 | 完成任务拿奖杯？不，完成躺平记录拿奖杯 |
| 🔓 奋斗模式 | 试图起身时触发 5 秒广告解锁，副作用：可能真的开始做事 |

## 🏆 反向成就一览

- 🪨 **《肉身沉重》** —— 连续 8 小时不起身上厕所
- 💭 **《意念回复》** —— 看到消息但假装已读 3 天
- 😴 **《圣堂休眠》** —— 在视频会议中睡着且没被点名
- 🕳️ **《终极坍缩》** —— 成功让同事也一起躺平
- 📉 **《自动降级大师》** —— 第一次启动「一键降级」
- 🧲 **《重力补偿》** —— 试图起身后被系统压回床上
- 🧘 **《得道高徒》** —— 向躺平导师请教一次
- 🪑 **《纸扎上岗》** —— 启动数字纸扎工位
- 🎧 **《内耗清零》** —— 播放一次电钻×冥想白噪音

每解锁一个成就，系统都会播放电子鞭炮声并配音：

> 「恭喜！您又浪费了一段可以赚钱的时间。请继续保持废物形态。」

## 🛠 技术

- 纯 **HTML + CSS + JavaScript**，单文件，无任何依赖
- 成就存档存于 `localStorage`（浏览器本地，不会上传）
- 音效 / 白噪音由 Web Audio API 现场合成，无音频文件
- 导师回复为关键词规则匹配，非联网 LLM
